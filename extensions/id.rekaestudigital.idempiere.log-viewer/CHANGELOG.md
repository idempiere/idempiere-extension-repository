# Changelog

All notable changes to this extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.1] - 2026-10-24

### Changed
- Removed the lazy activation flag from the bundle manifest.

## [1.0.0] - 2025-01-07

### Added
- First release: view, download, rotate and delete trace logs at `/log-viewer`.
- `LOG_VIEWER_LIMIT_SIZE` System Configurator setting for the largest file the browser will load.
